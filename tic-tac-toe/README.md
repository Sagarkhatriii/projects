# Tic-Tac-Toe

A two-player browser game built with HTML, CSS, and JavaScript, prepared.

## Run
Open `index.html` in your browser. No installation is required.

## Features
- Alternating X and O turns
- All eight winning lines and draw detection
- Winning-line highlighting and restart
- Keyboard accessible buttons and live status announcements
- Responsive layout

## Learn from the code
`outcome()` checks winning lines; the click handlers update the board and render the result. Try adding a score counter or a computer opponent.
